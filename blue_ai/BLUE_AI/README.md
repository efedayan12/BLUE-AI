# 🔵 BLUE_AI — Bilgisayar Yönetim Yapay Zekası

LLM modeli kullanmadan, kural tabanlı ve heuristik algoritmalarla çalışan, Windows bilgisayarını uçtan uca yöneten **yüksek performanslı** yapay zeka sistemi.

## 🚀 Hızlı Başlangıç

```bash
# Bağımlılıkları yükle
cd C:\BLUE_AI
pip install -r requirements.txt

# Sistem durumunu göster
python -m blue_ai status

# Çalışan süreçleri listele
python -m blue_ai processes

# Disk temizliği
python -m blue_ai clean --full

# Sistem optimizasyonu
python -m blue_ai optimize

# Ağ durumu
python -m blue_ai network

# Güvenlik taraması
python -m blue_ai security

# Başlangıç uygulamaları
python -m blue_ai startup

# Yüklü yazılımlar
python -m blue_ai software

# Profil değiştir
python -m blue_ai profile gaming

# Kuralları listele
python -m blue_ai rules

# Web Dashboard
python -m blue_ai dashboard

# Tam motor (arka plan modu)
python -m blue_ai run
```

## 📦 Modüller

| Modül | Açıklama |
|---|---|
| 🖥️ System Monitor | CPU, RAM, Disk, GPU, Sıcaklık izleme |
| 📋 Process Manager | Süreç yönetimi, hog tespiti, throttle |
| 📁 File Manager | Dosya arama, duplicate tespit, organizasyon |
| ⚡ Performance | Anomali tespiti, RAM temizleme, profil optimizasyonu |
| 🛡️ Security | Port tarama, şüpheli süreç, dosya bütünlüğü |
| 🌐 Network | Hız izleme, ping, DNS, bağlantı takibi |
| ⏰ Scheduler | Görev zamanlama, koşullu çalıştırma |
| 🚀 Startup | Başlangıç yönetimi, boot optimizasyonu |
| 🧹 Cleaner | Temp, cache, Windows Update temizliği |
| 🔋 Power | Pil izleme, güç profili yönetimi |
| 📦 Updater | Yazılım güncelleme takibi |

## 🎮 Profiller

- **Dengeli** — Varsayılan, her şey dengelerde
- **Oyun** — Maksimum performans, arka plan süreçleri minimize
- **İş** — Odaklanma modu, dengeli kaynak
- **Tasarruf** — Minimum enerji kullanımı
